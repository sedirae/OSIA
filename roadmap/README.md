# Roadmap — spécifications des fonctionnalités

Ce dossier reçoit **une spécification autonome par fonctionnalité importante** lorsqu'une évolution a été étudiée et suffisamment cadrée.

Aucune fonctionnalité n'est définie dans le template.

## Comment ajouter une fonctionnalité

1. Appliquer le mode **ÉVOLUTION** de [PROJECT-INIT.md](../PROJECT-INIT.md) en consolidant les discussions réellement accessibles.
2. Vérifier la compatibilité avec [`CADRAGE/`](../CADRAGE/README.md).
3. Créer un document descriptif explicite, par exemple `01-nom-de-fonctionnalite.md`, uniquement lorsqu'une fonction existe réellement. **Le numéro indique l'ordre de création/classement, pas la priorité.**
4. Inclure contexte, objectif, statut, périmètre, parcours, contraintes techniques/sécurité utiles, lots éventuels et critères de recette.
5. Référencer ce document depuis les missions de réalisation dans [`COWORKAI/missions/`](../COWORKAI/README.md).
